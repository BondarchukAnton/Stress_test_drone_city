# Stress_test_drone_city

Этот проект представляет собой структуру для тестирования дронов с использованием ИИ-агентов и ROS 2.

## Архитектурная схема

Архитектура проекта разделена на верхний уровень (ИИ-агенты + Qwen) и нижний уровень (ROS 2 / PX4 / Gazebo). Верхний уровень не зависит от нижнего уровня, что позволяет легко тестировать ИИ-агентов в симуляторе без необходимости запуска физических дронов.

## Запуск в симуляции (SITL)

1. Поднятие Gazebo:
   ```sh
   docker compose -f docker-compose.sim.yml up -d
   ```

2. Запуск моста ROS 2:
   ```sh
   python3 bridge/ros2/bridge_node.py
   ```

3. Запуск ИИ-агентов на хост-машине:
   ```sh
   python3 -m agent.loop
   ```

## Развёртывание на реальный дрон

1. Перенос содержимого папки `onboard/` на Raspberry Pi дрона.

2. Настройка файла `onboard/.env.drone` с указанием уникального `HANDLER_ID` (например, `drone_1`).

3. Запуск моста ROS 2 непосредственно на борту:
   ```sh
   python3 bridge/ros2/bridge_node.py
   ```

Такая структура позволит четко разделить среду разработки в симуляторе, код ИИ-агентов на ноутбуке и бортовой код для физических дронов PX4.
