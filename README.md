# Stress_test_drone_city

Этот проект представляет собой структуру для тестирования дронов с использованием ИИ-агентов и ROS 2.

## Установка

1. Клонируйте репозиторий.
2. Настройте переменные окружения в `.env.example`.
3. Создайте файлы конфигурации для агентов в `souls/`.

## Запуск

1. Сборка и запуск сервисов:
   ```sh
   make hub agents
   ```

2. Доступ к дашборду:
   Откройте браузер и перейдите по адресу `http://localhost:5000`.
